YouTube Playlist MCP

A Model Context Protocol server that lets Claude open a public YouTube playlist, list its videos and read their transcripts, so you can ask questions about a whole course instead of watching it.

Claude'ga ochiq YouTube pleylistini ochish, videolarini ro'yxatlash va transkriptlarini o'qish imkonini beradigan Model Context Protocol serveri: butun kursni ko'rmasdan, u haqida savol berasiz.

What MCP isMCP nima

The Model Context Protocol is an open standard for giving an AI assistant tools. A small server describes its tools with names, typed parameters and a docstring; the assistant reads those descriptions, decides when a tool helps, calls it, and reads the result like any other text.Model Context Protocol AI yordamchiga vositalar berishning ochiq standarti. Kichik server o'z vositalarini nomi, turli parametrlari va izohi bilan tasvirlaydi; yordamchi bu tavsiflarni o'qib, qachon vosita kerakligini o'zi hal qiladi, uni chaqiradi va natijani oddiy matndek o'qiydi.

This server gives Claude two tools for YouTube: list the videos of any public playlist, and read up to five transcripts at once. It runs on my machine and is reachable through a Cloudflare Tunnel, so it can be added to Claude as a custom connector.Bu server Claude'ga YouTube uchun ikkita vosita beradi: istalgan ochiq pleylist videolarini ro'yxatlash va bir vaqtda beshtagacha transkriptni o'qish. U mening kompyuterimda ishlaydi va Cloudflare Tunnel orqali ochiq, shuning uchun Claude'ga maxsus konnektor sifatida qo'shiladi.

  1. Claudedecides to call a toolvositani chaqirishni hal qiladi

The two toolsIkki vosita

Exact signatures from playlist_mcp.py. The docstring is what Claude sees as the tool's description.playlist_mcp.py dagi aynan shu imzolar. Izoh (docstring) Claude ko'radigan vosita tavsifi.

@mcp.tool()
def get_playlist_videos(playlist_url: str) -> str:
    """Return each video's position, ID, title, and URL from a public playlist."""

Uses yt-dlp in flat mode, so it lists hundreds of videos without downloading anything. Returns one line per video: position, ID, title and URL.yt-dlp'ni flat rejimda ishlatadi: hech narsa yuklamasdan yuzlab videoni ro'yxatlaydi. Har bir video uchun bitta qator qaytaradi: tartib raqami, ID, sarlavha va URL.

@mcp.tool()
def get_multiple_transcripts(
    video_ids: Sequence[str], languages: Sequence[str] = ("uz", "ru", "en", "tr")
) -> str:
    """Fetch transcripts for up to five YouTube video IDs, preferring the given languages."""

Capped at five IDs per call to keep the response a readable size. Tries Uzbek, Russian, English, then Turkish captions; a video without captions comes back as “[Transcript unavailable: …]” instead of failing the whole call.Javob o'qiladigan hajmda bo'lishi uchun bir chaqiruvda beshtagacha ID. Avval o'zbek, rus, ingliz, keyin turk subtitrlarini qidiradi; subtitri yo'q video butun chaqiruvni buzmaydi, “[Transcript unavailable: …]” bo'lib qaytadi.
